# 外部机器运行指南（RUNBOOK）

> 这份包可以在另一台机器（Windows / Linux，CPU 或 GPU）上复现训练与评估。
> 目标：跑完指定实验后，把 `runs/` 和 `results/` 打包回传。

---

## 0. 一分钟速览

```bash
# 1) 解压后进入目录
cd BISHE

# 2) 装依赖（GPU 请先按官网装好 CUDA 版 torch）
pip install -r requirements.txt

# 3) 生成数据（若包里没有 data/whu_processed）
python scripts/prepare_whu.py --root data/raw --out data/whu_processed --size 512

# 4) 训练（GPU 用 --device cuda --amp，CPU 去掉这两个参数）
python scripts/train_whu.py --data data/whu_processed --arch full --base 16 \
  --size 384 --shadow-aug 0.5 --shadow-weighted-loss --epochs 6 --batch-size 4 \
  --lr 2e-5 --device cuda --amp --init-from runs/whu_mt512/best.pt \
  --out runs/whu_shadow --resume

# 5) 评估
python scripts/evaluate_whu.py --model whu_shadow --split test --limit 300
python scripts/diagnose.py --model whu_shadow --limit 300

# 6) 打包回传
zip -r results_back.zip runs results
```

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.10 – 3.12（3.13 也可，但部分 wheel 可能缺失） |
| 内存 | ≥ 8 GB（512 输入训练建议 16 GB） |
| 显存 | 可选；6 GB 可跑 512/batch 8，12 GB 可跑 1024/batch 4 |
| 磁盘 | 代码 2 MB + 原始数据 700 MB + 处理后数据 8 GB |

安装：

```bash
pip install -r requirements.txt
# GPU 机器：先装 CUDA 版 torch，例如
# pip install torch --index-url https://download.pytorch.org/whl/cu121
```

检查：

```bash
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

## 2. 数据准备

### 情况 A：包里已含 `data/whu_processed/`

直接跳到第 3 步。目录应包含：

```
data/whu_processed/
  train_images.npy  train_masks.npy
  valid_images.npy  valid_masks.npy
  test_images.npy   test_masks.npy
  meta.json
```

### 情况 B：包里只有 `data/raw/`（108 个 tif）

```bash
python scripts/prepare_whu.py --root data/raw --out data/whu_processed --size 512
```

约 10–20 分钟，产出 8 GB 的 memmap 文件。

> 若手上是 WHU 原始压缩包（0.3 m 的 cropped tiles），先解压成
> `data/raw/{train,valid,test}/{sat,map}/xxx.tif` 这种结构即可。

## 3. 实验清单（按优先级）

### E1 阴影感知训练（**最优先**）

```bash
python scripts/train_whu.py --data data/whu_processed --arch full --base 16 \
  --size 384 --shadow-aug 0.5 --shadow-weighted-loss \
  --epochs 6 --batch-size 4 --lr 2e-5 --pos-weight 1.5 --edge-weight 0.5 \
  --device cuda --amp --num-workers 4 \
  --init-from runs/whu_mt512/best.pt --out runs/whu_shadow --resume
```

| 平台 | 预计 |
|---|---|
| CPU 12 线程 | 3 小时 |
| RTX 4090 | 8–12 分钟 |

> 需要 `runs/whu_mt512/best.pt`。若包里没带，请先按 E4 的说明联系我们获取，
> 或改为不加 `--init-from`（从头训，效果会差）。

### E2 1024 分辨率（**未知收益最大**，仅 GPU）

```bash
python scripts/train_whu.py --data data/whu_processed --arch full --base 16 \
  --size 1024 --epochs 8 --batch-size 4 --lr 1.5e-5 \
  --pos-weight 1.5 --edge-weight 0.5 \
  --device cuda --amp --num-workers 4 \
  --init-from runs/whu_mt512/best.pt --out runs/whu_1024 --resume
```

| 平台 | 预计 |
|---|---|
| RTX 4090 | 40–60 分钟 |
| CPU | 不建议（约 30 小时） |

### E3 BIEB 完整性分支 512（次优先）

```bash
python scripts/train_whu.py --data data/whu_processed --arch full --base 16 \
  --size 512 --bieb --bieb-weight 0.2 --epochs 8 --batch-size 4 --lr 1.5e-5 \
  --pos-weight 1.5 --edge-weight 0.5 --device cuda --amp --num-workers 4 \
  --init-from runs/whu_bieb/best.pt --out runs/whu_bieb512 --resume
```

### E4 评估与诊断（跑完训练后）

```bash
# 全量测试集阈值扫描
python scripts/evaluate_whu.py --model whu_shadow --split test

# 阴影子集对比
python scripts/eval_occlusion.py --subset data/shadow_subset.json \
  --models whu_mt512 whu_shadow --threshold 0.55

# 误差来源诊断（分区/分尺寸/FP-FN 构成/置信度）
python scripts/diagnose.py --model whu_shadow --limit 300
```

## 4. 需要回传的东西

```
runs/<实验名>/best.pt          ← 权重（最重要）
runs/<实验名>/train_log.csv    ← 每轮指标
runs/<实验名>/eval_test*.json  ← 评估结果
results/*.json                 ← 诊断与对比
```

打包：

```bash
# Linux / macOS
zip -r results_back.zip runs results
# Windows
Compress-Archive -Path runs,results -DestinationPath results_back.zip
```

如果结果较大，只回传 `runs/*/best.pt` + 所有 `*.csv` / `*.json` 即可。

---

## 5. 注意事项

1. **不要改 `data/` 里的文件**，否则结果不可比；
2. 训练默认 `seed=42`，请勿修改 `.py` 里的随机种子；
3. 显存不足时把 `--batch-size` 降到 2 或 1，**其余参数保持不变**；
4. 中断后重跑同一条命令（带 `--resume`）即可续训；
5. 每轮日志写在 `runs/<实验名>/train_log.csv`，出现 NaN 或 val IoU 长期不涨请截图告知。

---

## 6. 各实验的预期数值（用于判断是否跑对）

| 实验 | 起点 | 预期 val IoU | 说明 |
|---|---|---:|---|
| E1 阴影感知（384，6 轮） | whu_mt512 | 0.86–0.88 | 阴影像素召回应从 0.84 提到 0.87+ |
| E2 1024（8 轮） | whu_mt512 | 0.88–0.91 | 分辨率提升，未知上限 |
| E3 BIEB（512，8 轮） | whu_bieb | 0.87–0.89 | 与同条件对照比较 |

若数值明显偏离（如 < 0.80），多半是数据或起点权重不对，请先核对。
