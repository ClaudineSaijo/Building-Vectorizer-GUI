# 文献对照与路线调整（2026-11-01 夜）

> 8 篇 PDF 已读（全文文本在 `papers/*.txt`）。本文记录：每篇能用的部分、
> 我自己复现后的实测结论、以及对第 3/4 章路线的影响。

## 1. 遮挡相关（3 篇）

### BIENet（TGRS 2024）— 可借鉴，成本中等

- **做法**：用**标签**从原图合成"增强图"——每栋建筑取内部均值色 → 与原图按比例融合 →
  前景提亮、背景压暗，得到"无遮挡、高对比、轮廓完整"的图；
  再用一个**额外的解码器（BIEB）重建这张增强图**作为辅助监督，分割分支同时用编码特征和 BIEB 特征；
  外加残差学习（BRL）。
- **结果**：WHU 上比 HD-Net **+1.49 IoU / +0.82 F1**（Massachusetts、Inria、AIRS 也有提升）。
- **代码**：github.com/tqwhdx19/bienet。
- **对我们的意义**：它证明"**给目标**（重建增强图）比"**给提示**"（我们加的 4 通道先验）更有效。
  我们 4 通道实验 val 从 0.8864 掉到 0.8676→0.8504，正好印证这一点。

### BOMSC-Net（TGRS 2022）— 最贴合我们的遮挡问题

- **问题陈述**：明确指出"树和阴影遮挡导致提取结果**不连续**"。
- **模块**：方向场优化模块（DFOM）——预测**方向场**，用方向信息修正边界。
- **对我们的意义**：方向场就是"边界该往哪走"，遮挡处可以沿场延续；
  比我们手写的"方向一致性直线跨接"更系统、且可学习。
  **成本最低**（加 2 通道头），**最值得先做**。

### PCL–PTD Net（JSTARS 2023）— 参考价值低

并行交叉学习 + 像素转移反卷积，编码器结构技巧，与"矢量输出"目标不搭，只作相关工作引用。

## 2. 矢量化/多边形化（4 篇）

### GCP：Global Collinearity-Aware Polygonizer（TGRS 2025）— 已复现，结论是"没有明显优势"

- **做法**：Mask2Former 掩膜 → 采样折线 → Transformer 回归精化 → **共线性感知的 DP 简化**
  （目标 `L(p, p̂) + λ|p̂|`，L 为被删点到对应线段的距离和），全局最优。
- **论文主张**：该简化模块用于任意折线时，优于 Douglas-Peucker。
- **我复现了简化模块**（`src/polygonize_gcp.py`），在我们 97 个预测多边形上实测：

| 方法 | 平均顶点 | 到原多边形 Chamfer |
|---|---:|---:|
| DP（ε=1.2%） | **6.64** | **0.938** |
| GCP λ=1.6 | 8.55 | 0.768 |
| GCP λ=3.0 | 7.52 | 0.904 |
| GCP λ=5.0 | 6.79 | 1.052 |
| GCP λ=8.0 | 6.03 | 1.261 |

**结论**：在**相同顶点预算**下（≈6.6），DP 的 Chamfer 反而更好（0.938 vs 1.05）。
GCP 的价值是提供了**平滑的"保真度—压缩率"可调曲线**（λ 单调控制），
而不是"更少的顶点"。

→ **对我们的意义**：说明**瓶颈不在"简化算法"，而在掩膜本身的锯齿**。
这也解释了 GCN 为什么压不下顶点：输入轮廓本身就是抖的。

### Machine-learned Regularization and Polygonization（ICPR 2021）

- **做法**：FCN 分割 → **GAN 规整化边界**（更接近直角/规则轮廓）→ 再训练 CNN 从规整化结果
  预测**稀疏角点**。
- **对我们的意义**："先规整再取角点"的顺序很聪明；我们目前是"先取角点再规整"。
  可作为第 4 章的一个对比方案（若时间允许）。

### CornerDYO（IEEE Access 2026，开放获取）

- **做法**：多尺度特征 + 双向融合 + **角点感知精化** → 角点与边联合预测 → 平面图构建。
- **对我们的意义**：和"像素中检测特征点再连边"最接近的最新工作，值得细读其角点标注与连接规则。

### Vertex Aided Building Polygonization（JURSE 2023）

- **做法**：RGB 直接出多边形，**不需要预设顶点数、不需要阈值**；AP 48.1%、IoU 84.1%。
- **对我们的意义**：证明"端到端出顶点"可行；但它的指标口径与我们不同，只能定性比较。

## 3. 不适用的（2 篇）

- **Amodal 数据集（TGRS 2024）**：MVB-Zurich / MSB-Dortmund 都是**倾斜多视角**数据，不是正射航空图，
  无法直接用于 WHU；其"遥感边界损失"可借。
- **PCL–PTD Net**：见上。

## 4. 路线调整

| 原计划 | 调整后 | 理由 |
|---|---|---|
| 4 通道先验为主攻 | **降级为消融**（明天跑完第 3 轮就收） | 实测 val −1~3 点，文献也说明"提示不如目标" |
| 无 | **新增：方向场头（2 通道）** | BOMSC 证明有效，成本最低，直接服务矢量连续性 |
| 无 | **新增：完整性重建分支（BIEB）** | BIENet 证明有效，可作第 3 章第二个卖点 |
| GCN 压顶点 | **GCN 定位改为"保真度精化"**，压缩交给 DP/λ 曲线 | 实测 GCN 顶点 7.3 > DP 6.2；文献表明瓶颈在掩膜 |
| 无 | **新增：λ 可调的 GCP 简化**，用于画"顶点数 vs Chamfer"曲线 | 论文里是很漂亮的一张图 |
